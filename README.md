# 🎬 Netflix Inspired Movie Recommendation System

A machine learning based movie recommendation system that suggests similar movies based on user-selected preferences.

## 🚀 Features

- Content-based movie recommendations
- Machine learning similarity calculation
- Interactive Streamlit web application
- Netflix-inspired user interface

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

## 🧠 How It Works

1. Movie dataset is processed and cleaned.
2. Movie information such as overview, genres, and keywords are combined.
3. Text features are converted into numerical vectors using CountVectorizer.
4. Cosine Similarity is used to find similar movies.
5. Streamlit provides the interactive web interface.
